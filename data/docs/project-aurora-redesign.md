## Executive Summary
Project Aurora is Brightwave Digital’s comprehensive internal digital transformation and flagship website redesign. Tarun Shah (Lead Full-Stack Architect) oversees engineering, collaborating with Creative Lead Pooja Shah and Strategy Lead Rohan Mehta.

## Strategic Objectives and Target Outcomes
The legacy WordPress agency portal is being phased out due to performance bottlenecks and security vulnerabilities. Project Aurora aims to establish Brightwave as India's premier high-tech digital agency:
1. Elevate organic search discovery by targeting competitive enterprise SEO keywords across Mumbai, Delhi NCR, and Bengaluru.
2. Achieve 100/100 Core Web Vitals across mobile and desktop devices.
3. Boost inbound lead conversion rate from 1.8% to 4.5% via dynamic interactive calculators.
4. Target production deployment date is November 15, 2026, with staging validation commencing October 20.

## Technical Architecture & Approved Stack
- **Framework**: Next.js 15 (App Router with React Server Components) deployed on Vercel Enterprise.
- **Styling**: Tailwind CSS utilizing Brightwave's proprietary design token library (primary accent `#2F6F6B`).
- **Headless CMS**: Sanity.io for structured editorial content, author profiles, and case study taxonomies.
- **Analytics & Tracking**: Server-side Google Tag Manager with BigQuery data stream and Microsoft Clarity heatmaps.
- **Integrations**: HubSpot CRM form webhooks, Cal.com scheduling embeds, and WhatsApp Business API gateway.
